So, I thought I should share one of the projects I did to streamline some tasks we do in construction. If I'm going to write a production report every day and compile them after a week and then compile the weekly further into monthly then later to quarterly - that's kinda repeating yourself, right? Maybe something that would help for that task would be an aggregator kind of project. That way I spend less time manually compiling and more time working on other tasks. So I built something lightweight to help with that. As you can see, it even goes further. It's a lightweight project, only meant for one of the sites in progress somewhere. We run it locally because of we did not, we would have a few #dataprivacy concerns. It's only meant to streamline our work locally, so it's not production grade at the moment. The data shown here is mock data, but it works with real data. We've relied on it for a few months now.#contech #engineering #constructionmanagement
