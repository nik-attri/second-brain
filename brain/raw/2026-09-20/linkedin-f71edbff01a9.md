How do you teach a computer to recognize a cat? 

In the past, you had to write thousands of rigid rules detailing ear shapes, whisker lengths, and tail curves. Today, we simply show the computer 10,000 pictures of cats and let it figure out what a cat looks like. 

This is the core shift of Machine Learning.

Day 11/365 — What is Machine Learning (ML)?

Yesterday, we compared AI models with traditional software. We learned that traditional software relies on explicit rules (if/then statements) written by a human programmer. But what happens when a problem is too complex for human-written rules?

This is where Machine Learning (ML) enters the picture.

Machine Learning is a subset of Artificial Intelligence that gives computers the ability to learn without being explicitly programmed. Instead of writing the rules ourselves, we feed the computer data and use mathematical algorithms to let the computer discover the rules on its own.

Think of it as shifting from:
"Human writes code to process data" 
to 
"Computer uses data to write its own logic."

How it Works

Think of Machine Learning as a three-step cycle:

1. Input Data: We feed the system historical data (for example, house sizes and their actual sale prices).

2. Pattern Recognition: The ML algorithm analyzes this data to find mathematical relationships (for example, how much each additional square foot adds to the price on average).

3. Prediction & Generalization: The system builds a mathematical model. When we show it a new house size it has never seen before, it uses the discovered patterns to predict the price.

Practical Example: Spam Filters

Let's look at email spam filters.

In traditional software, you would manually write a list of spam words like "buy now" or "free money." But spammers quickly bypass this by writing "b.u.y n.o.w."

With Machine Learning, the filter is fed millions of emails already marked as "spam" or "not spam." The ML algorithm analyzes these emails and finds thousands of subtle, interconnected patterns (word choices, sender metadata, sending times) that humans would never notice. If spammers change their tactics, we don't rewrite the code; we simply retrain the ML model on the new data, and it adapts.

Under the Hood

How does a computer actually "learn"? It uses an Algorithm to build a Model.

The algorithm is the mathematical recipe (the rules of learning). The model is the output—the digital brain that has successfully learned the patterns.

To learn, the algorithm uses parameters (think of them as millions of tiny, adjustable dials). During the training phase, the algorithm makes a prediction, compares it to the correct answer, calculates how wrong it was, and adjusts its dials to make a better prediction next time. This adjustment process is repeated millions of times until the errors are minimized.

Study Notes:

- Machine Learning is the science of getting computers to learn patterns from data instead of following manual, step-by-step rules.

- The process shifts from Rule-Based (Inputs + Rules = Answers) to Learning-Based (Inputs + Answers = Rules).

- Learning happens through training, where an algorithm constantly adjusts its internal parameters to minimize its prediction errors.

Key Takeaway:
Instead of programming the solution, we program the machine to find the solution.
