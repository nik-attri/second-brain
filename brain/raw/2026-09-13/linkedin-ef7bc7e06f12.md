POWER QUERY CHANGED HOW I LOOK AT MESSY DATA

One thing I quickly realised during my Data Analytics journey at CRESDIG Innovation Hub is this:

Data is not always ready for analysis.

You can have a dataset with thousands of rows, but before you start creating charts or looking for insights, there is usually some work that needs to be done first.

Missing values.

Wrong data types.

Duplicate records.

Columns that need to be separated.

Different spellings for the same thing.

And honestly, this is where Power Query became really useful.

At first, I saw data cleaning as something you simply had to do before analysing data.

But as I continued learning, I realised that cleaning data is a very important part of the entire analytics process.

Because no matter how beautiful your dashboard looks, the insights may not be reliable if the data behind it isn't properly prepared.

Learning Power Query under the supervision of my instructor Ibrahim Aremu, BIDA™, I learned how to make different transformations to prepare data for analysis.

Some of the things I learned include:

• Changing data types: making sure numbers, dates, and text are in the correct format.

• Removing duplicates to avoid counting the same information more than once.

• Replacing values: useful when there are errors or inconsistent values in a dataset.

• Splitting columns especially when different pieces of information are combined in one column.

• Creating custom columns to add new information based on existing data.

• Merging queries when you need to bring related data together.

• Appending queries when you want to combine similar datasets into one.

What I find interesting about Power Query is that it makes the cleaning process more organised and repeatable.

Instead of manually fixing the same issues every time, you can apply transformation steps and refresh your data when needed.

That was a big lesson for me.

Data cleaning might not be the most glamorous part of Data Analytics, but it is one of the foundations of good analysis.

Because before asking, “What is the data telling us?”

We first need to make sure the data is ready to tell the right story.
