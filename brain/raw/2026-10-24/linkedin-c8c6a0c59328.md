AI is changing the cybersecurity landscape faster than we think.

On Friday, we woke up to news of PHP vulnerabilities affecting millions of systems worldwide, reportedly identified with the help of AI agents. It raises an uncomfortable question: how many vulnerabilities have been sitting undetected in production systems for years?

Today, AI agents can analyse code repositories and identify potential security flaws at a speed and scale that would have been difficult to achieve manually.

And here’s the challenge: much of the digital world runs on open-source software.

Open source has enabled us to build powerful, scalable systems faster than ever. But every dependency, every external library and every line of generated code can also introduce potential security risks.

So, what should we do?

🔹 Audit AI-generated code before deployment.
🔹 Review third-party dependencies and open-source components.
🔹 Integrate automated security testing into CI/CD pipelines.
🔹 Make security everyone’s responsibility throughout the development lifecycle.

Security cannot be something we address after a vulnerability makes the headlines. It must be built into the way we develop, integrate and deploy software.

SecDevOps is no longer just a best practice. It’s becoming a necessity.
