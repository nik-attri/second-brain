A few weeks ago I built a dashboard prototype with Claude Code in a handful of working sessions. Halfway through I had to add a badge to every number saying whether the value came from a real source or was illustrative, because the mockup looked equally finished in both cases.

It felt familiar. In the 2000s it was spreadmarts, Excel files doing the job of a data warehouse, and TDWI found them in more than 90% of organizations. In the 2010s self service BI brought dashboard sprawl, with the same KPI showing three values in three meetings. AI assistants can now produce the equivalent of both in minutes, with a confident narrative on top.

Fencing the tools in does not work. 78% of AI users already bring their own tools to work, and when TDWI asked what had worked against spreadmarts, new spreadsheet policies were rated very effective 12% of the time.

In the new piece I propose a different approach:
1) A matrix of data culture and infrastructure maturity that sets the pace of empowerment for each quadrant

2) A five question test with green, amber and red zones, so people know when an artifact stops being personal

3) A governed road where publishing to a shared space takes less effort than keeping a file on the desktop

This week a16z described the future of the firm as shared memory with decisions spread across the company. Artifacts hell is what you get when the memory is spread across desktops too.
