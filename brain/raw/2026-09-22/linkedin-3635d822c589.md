In the last 6 weeks I’ve realised something. 

People are asking the wrong questions about AI.

The question shouldn’t always be:

“What can this AI tool do?”

It should be:

“What problem are we trying to solve?”

If a team is spending hours every week on repetitive data entry, that’s a problem worth looking at.

If someone is manually gathering the same information for a report every month, that’s a problem worth looking at.

If a process involves copying the same information from one system into another, that’s a problem worth looking at.

If I’m spending my time creating the same training materials over and over again, that’s a problem worth looking at.

Only then does the technology conversation become useful.

I’m increasingly interested in AI because I can see the potential to remove the repetitive, time-consuming work that takes people away from the things where they actually add value.

But I’m not interested in using AI simply because we can.

If we’re going to introduce another tool, another process or another layer of technology, there needs to be a reason for it.

Otherwise we’ve just found a more complicated way of doing something we didn’t need to be doing in the first place.

Start with the problem.

Make a list.

Then find the technology.

Not the other way around.
