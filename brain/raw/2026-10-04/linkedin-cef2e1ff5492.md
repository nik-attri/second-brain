🚀"Torture the data, and it will confess to anything." — Ronald Coase 

Working with raw data requires strict quality controls to ensure we get honest, actionable business insights instead of forced conclusions.
During Week 4 at #DigitalSkola with Kelompok 2 (Gemini), we bridged the gap between automated spreadsheet workflows and advanced database querying! 📈

Key takeaways from our hands-on sessions: 
• Automated Spreadsheet Auditing: Combining Power Query for ETL, Data Validation to block illegal user inputs, and Excel Macros to automate multi-step formatting into a single button click. Golden Rule learned: Power Query for cleaning, Macros for final formatting! 

• Core SQL Querying: Constructing complete SQL queries (SELECT, WHERE, GROUP BY, HAVING, ORDER BY, LIMIT) to extract precise data subsets. 

• Advanced Analytics in SQL: Utilizing Common Table Expressions (CTEs) for readable, modular code, joining relational tables, and using Window Functions (PARTITION BY / ORDER BY) to compute running metrics and rankings without collapsing data rows. 

Mastering these tools brings me one step closer to designing end-to-end BI solutions that drive real business decisions! 💡 Data-driven all the way.
