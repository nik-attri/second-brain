After learning about Lambda Expressions yesterday, today I explored another powerful feature of Java:

🌊 Stream API in Java

The Stream API helps us process collections of data in a clean and readable way. It allows us to perform operations such as filtering, sorting, mapping, and collecting results without manually managing every step of iteration.

🌍 Real-life example

Imagine having a list of students with different marks. 🎓

What if we want to find only the students who scored above 80, sort their marks, or calculate the results?

Instead of writing multiple loops, we can use the Stream API to process the data through a sequence of operations.

📚 What I learned today:

🔹 What is the Stream API
🔹 Why Streams are useful
🔹 Creating Streams from collections
🔹 Using "filter()" to select elements
🔹 Using "map()" to transform elements
🔹 Using "sorted()" to sort data
🔹 Using "forEach()" to process elements
🔹 Using "collect()" to gather results
🔹 Understanding intermediate and terminal operations
🔹 Introduction to "reduce()"
🔹 Difference between collections and streams

💻 Practice

After understanding the concept, I practiced 4 small coding problems using the Stream API.

I worked on filtering even numbers, finding numbers greater than a given value, transforming values using "map()", and sorting elements in a collection.

These exercises helped me understand how Streams and Lambda Expressions work together to make data processing more concise and readable.

🧠 Today's Takeaway

Today I understood:

Stream API → Processes data through a sequence of operations.

"filter()" → Selects elements based on a condition.

"map()" → Transforms elements.

"sorted()" → Sorts elements.

"collect()" → Gathers processed results into a collection or another result container.

I also learned that Streams do not usually modify the original collection, and many stream operations are evaluated only when a terminal operation is executed.
