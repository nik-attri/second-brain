📂 Opening a file → pd.read_csv()
👀 Scrolling the top rows → df.head()
🔽 Applying a filter → df[df['age'] > 30]
🔃 Sort A to Z → df.sort_values()
📊 Pivot table → df.groupby().agg()
🔍 VLOOKUP → pd.merge()
