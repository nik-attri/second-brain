I attempted to dabble in AI vibe coding last night.  I went into AI mode on Google (yeah, I know, there are multiple much better options, but this one was free and I knew where to find it) and asked it to build a VBA program in Excel that reads heart rate monitor data using an ANT+ to USB adapter and logs it in a spreadsheet.  Gemini explained that this was very difficult and suggested a Python reader that published data to Excel.  I agreed and said let's simplify this even more and build a Python program that logs to a CSV file.  From there I spent two hours in AI hell, during which it almost correctly told me how to fix a PATH issue on my PC (and I ended up irreversibly editing my USER PATH, not my SYSTEM PATH), helped me download an ANT+ module for Python, produced at least five non-functioning Python, programs, asked me to download some random software to replace drivers on my PC, and of course gave me that standard "Oh, NOW I know what's going on" vibe.  After all this, I gave up.  I suspect that one of the two of us is too dumb to be part of this project, so I might have to start asking Gemini to explain how Python, the ANT+ protocol and heart rate monitors work so that I can just write the damn code myself.  Not the most auspicious start.
