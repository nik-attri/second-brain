GenAI is quietly changing how a program manager spends the working week. 

A large part of delivery work has always been repetitive. Trackers need updating, and the same kind of report gets prepared again and again. This work matters, yet it leaves little room for the decisions that actually move a release. 

In my current role, I have integrated ChatGPT and Codex into our development workflows to automate repetitive engineering tasks. This has created 30+ hours of additional team capacity every sprint. 

For a program manager, a gain like this changes the planning conversation. The question moves from how to get routine work done to how the team should use the time it has won back. 

This is where program and project management roles are heading. When tools handle the repeatable parts of the job, the managers value sits in judgement. Knowing which risk deserves attention today and which stakeholder needs to hear difficult news early is work that a tool cannot own. 

GenAI also raises the bar. When reports and summaries are easy to produce, leaders expect them to be accurate and timely every week. The manager who understands the tools can set that standard for the whole team. 

Program managers who learn to use GenAI well will have more time for risk and for people, and those are the parts of the role that decide whether a release lands. 

How has GenAI changed the way you spend your working week so far?
