Having a personal agent will be like having a smartphone.

Remember Her? Theodore installs an operating system named Samantha. He's suspicious at first, gives it a shot, and everything changes for him.

What makes Samantha interesting is that she's persistent. She understands context and quietly handles the work that overwhelms him in the background. That's what we need for our day-to-day tasks.

We don't need a frontier model for our daily lives. Coding agents already proved models can write proper, working code, and if you can write code, you can do lots of things. What we need is a working, persistent agent that is easy to access and use. That will be the iPhone moment of AI.

It's the same path computers and smartphones took. Engineers and hackers adopt them first and build their own versions. Then someone makes them simple enough for everyone. Today's personal agents are still techy products. Consumers need simple ones.

A small example: ordering food. My agent knows me and my order history, so it can pick something I'd like. Better, it can pick something that fits my fitness goals and keep me from ordering junk.

A work example: I changed our API and asked my agent to write a doc for our mobile developer. I sent it over, he gave it to his agent, and they discussed it.

That's where this is going. People will start messaging each other's agents. My agent will write to my friend's agent and they'll arrange most of the details. Since each agent knows its owner, the messages will still sound like us.

I expect a new protocol for agent-to-agent communication, similar to MCP. Email for agents.

Trust is the next step. LLMs aren't predictable, and we've all seen the agent that deleted a database and apologized. But that's a human problem too. Programmatic guardrails will do the job.

The next one-person billion dollar companies can't happen without personal agents. One human can't reach every issue or manually organize every agent. You need one agent that organizes the rest.

That's why I'm pivoting Tamo into a personal agent that does what you want without making you learn what a model is. It shows you outcomes. You don't need to learn how the task is done.

What's the first task you'd delegate to an agent?
