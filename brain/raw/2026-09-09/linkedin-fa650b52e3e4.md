An e-commerce seller in Delhi 
was drowning in returns.

500 orders a month.
80-100 returns every month.

Each return handled manually:

Customer WhatsApps complaint.
Staff checks order details.
Staff verifies return reason.
Staff approves or rejects.
Staff coordinates pickup.
Staff updates inventory.
Staff processes refund.

7 steps. Every. Single. Return.

2 staff members doing 
nothing but handling returns.
Full time. Every day.

Cost of returns processing:
₹180-220 per return.
80 returns = ₹16,000/month
just in staff cost.

Plus missed orders because 
staff too busy with returns.

We built a returns management system:

Customer raises return request online.
Reason selected from menu.
Auto-approval for eligible returns.
Pickup scheduled automatically.
Inventory updated in real time.
Refund processed automatically.

7 manual steps → 1 customer action.

3 months later:

Return processing cost: 
₹200 → ₹35 per return.
Staff handling returns: 2 → 0.
Return resolution time: 
3 days → 4 hours.
Customer satisfaction: Up.

Those 2 staff members now 
handle customer acquisition.

Not returns.

to do work that software 
should be doing?
