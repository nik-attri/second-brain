Managing a college arts festival shouldn't mean drowning in scattered spreadsheets and manual sign-up sheets.

To solve this problem at IES College of Engineering, I built Academic Glow, an in-memory Java web application designed to streamline campus event management from the ground up.

Instead of manually tracking schedules and participants, the platform automates the logistical heavy lifting. The core features I developed include:
🔹 A centralized dashboard for dynamic event scheduling and agenda management.
🔹 Seamless participant registration flows for students.
🔹 Real-time coordination tools so organizers always have an up-to-date overview of the festival.

Building the backend architecture in Java was a great technical challenge, specifically in structuring the data flow and optimizing a clean, highly functional UI for both students and coordinators.

You can check out the live project here:  academicglow.vercel.app

I would love to hear feedback from other developers, or connect with anyone who has tackled event management tech!
