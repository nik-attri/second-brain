I’ve been thinking about what we actually want AI to give us

Because most of the conversation seems to be:

“Look how much time this can save!”

Amazing. Save the time. But then what?
Give ourselves 47 more tasks?
Add another meeting?
Answer more emails?
Fill the newly created space with even more work?

That feels like we’ve missed the point.

If AI can write the first draft…
🤘Maybe I can spend more time thinking about whether it’s actually any good.

If AI can summarise the meeting…
🤘Maybe I can spend more time having the conversation we actually needed to have.

If AI can analyse the data…
🤘Maybe I can spend more time working out what the hell it means.

If AI can automate the admin…
🤘Maybe managers can spend more time actually talking to their people.

And this is bit I’m really interested in

What happens when we stop measuring the value of AI by how much more work humans can do?

What if we measured it by how much more human humans can be?

More time to think.
More time to create.
More time to listen.
More time to build relationships.
More time to coach.
More time to challenge.
More time to have the difficult conversation.
More time to notice that someone in your team isn’t quite themselves.

Because those things are messy.

They’re slow.
They’re contextual.
They’re emotional.
They’re human.

And that’s exactly why they’re valuable.

I don’t want AI to help me become a more efficient version of a spreadsheet.

I want it to take some of the repetitive, administrative, mind-numbing crap off my plate so I can spend more of my time doing the things that require judgement, curiosity, empathy and imagination.

The irony would be pretty spectacular if we spent billions teaching machines to behave more intelligently… while teaching humans to behave more like machines.

So yes.

Let’s use AI to save time, automate the boring stuff and make work easier.

But then let’s actually do something with the time we get back.

The best use of AI might not be helping humans do more work.

It might be giving humans more time to do the work only humans can do.
