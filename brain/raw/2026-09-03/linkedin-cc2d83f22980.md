How do you handle the logging of audit trail events in your production environment? Locally, using additional storage media, proprietary software, or even manually?

Knick has developed an innovative audit trail solution for the Protos II 4400(X) transmitter that complies with the requirements of FDA 21 CFR Part 11. All events at the measuring point, changes, user actions, and complete sensor calibration reports are provided as plain text directly via the fieldbus. 
No proprietary software is required, and it prevents media interruptions caused by local storage media, data loss, and transmission errors.
On the customer side, these events can be retrieved fully automatically via the fieldbus, transmitted to control systems or databases, stored and analyzed there, and are immediately available. 

The required access control was implemented as a remote login via fieldbus with two-factor authentication and the requirement to provide a reason for the login. Users and roles are managed centrally through existing authentication systems, eliminating the need to maintain them directly on each transmitter.
