I’m starting to think about AI in software development less as a replacement for developers and more as the next big framework or abstraction layer.

Every major step in software development has allowed us to build more while doing less manually. High-level languages replaced low-level work. Frameworks like Spring, Rails or React removed thousands of things we used to build ourselves. Cloud platforms made infrastructure available through an API.

None of this killed software development. We just started building much more software.

And every time development became cheaper and faster, expectations grew with it. I think AI will push this much further.

Today we are impressed when one engineer with AI agents can do the work that previously required several people. But once this becomes normal, I don’t think investors or customers will say: “Great, now build the same product with five times fewer developers.”

More likely they will ask: “If you can build five times faster, why isn’t your product five times better?”

A five-person startup may soon be expected to deliver what we currently expect from a team of twenty. Personalization, automation, intelligent interfaces, integrations and great UX may simply become the baseline.

And this is also why I don’t agree that young developers no longer need to learn programming because AI can write code.

Writing code and understanding software are two very different things.

AI can generate the code, but someone still needs to understand why a database query will become slow, what happens during a race condition, where the security risks are, why one architecture will scale and another won’t, and whether the solution is actually good or simply works.

So if I were learning software development from zero today, I would absolutely still learn programming. I’d learn at least one language properly, but I wouldn’t make syntax my main goal. I’d focus on architecture, databases, networks, security, debugging, testing and understanding how software actually works.

And I would use AI from day one.

The next generation of great developers won’t compete with AI in writing code. They will use it to build things that were previously too expensive or too complex to build.

Maybe AI won’t make software engineers unnecessary. Maybe it will make today’s definition of a productive software engineer obsolete - while raising the bar for software itself.
