When we started designing MRDCL Hub three years ago, flexibility was a basic requirement.

Projects needed to accept data from different sources, run different analyses and deliver results to different systems. That shaped the design: build on MRDCL’s processing capabilities, make analysis easier to automate, and allow the workflow to fit the project.

AI has since given us more ways to simplify that work. It can help interpret instructions and assist with tasks that would otherwise require more manual specification.

Our development decisions come down to where that assistance is useful. Adding AI to a process needs a clear reason. Automation can often handle repeatable steps reliably. 

When interpretation or judgement is needed, AI can support the process, with users able to review the result and make changes. Each addition needs to improve the workflow.

MRDCL Hub is becoming the environment where these parts work together: easier data movement, automated analysis and AI assistance where it serves a practical purpose.

The available tools have changed considerably. The objective remains consistent: make difficult work easier while keeping users in control of how their projects are handled.
