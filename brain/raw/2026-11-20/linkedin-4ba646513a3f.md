One of the hardest things about making a change in an Excel model is making sure you tweak every relevant formula. In portfolio models this is even harder.

I often end up making a list on physical paper of all the places I need to make changes, and manually ticking them off one by one as I work through. Get to the end. Am I sure I made the amendments in all relevant assets? Am I confident I approached everything consistently?*

Generally, my go to approach for cross checking that I've made all the necessary changes in a model is to use the Operis Analysis kit. The "Compare" function can list all the changes between two versions and I can compare** that against the locations where I expect something to have been updated.

If I were inclined to let Claude or something similar loose on real models for live deals (I am not currently so inclined) I would consider this step even more vitally important.

But historically, even with OAK, it's been a bit cumbersome to take a portfolio model and check that all the asset worksheets are in lockstep with each other where they should be, and are not where they shouldn't be. It could be done, but only on a pairwise basis. But not any more in the new release of OAK! It will now be possible to compare multiple worksheets within one Compare run. This is the cause of much rejoicing in our audit team.***

So, if you're an OAK user and you build portfolio models, make sure you update to the latest release. And if you don't know what on Earth I'm talking about and you'd like to give OAK a try then do take advantage of the free trial.
