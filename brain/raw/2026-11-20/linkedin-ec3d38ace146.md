Automation has followed me through my whole career. Now it is easier than ever to build.
I started my professional life in automation, and it has stayed with me ever since. 
Even now, leading GRC across several organisations, it is one of my most useful tools.

When I was in the risk management team at KPMG, 
we used SharePoint workflows, the forerunner of what is now Power Automate, to take repetitive work off our desks. The lesson stuck. Small automations save a surprising amount of time.

Today my GRC work runs on many of them:
▪️ Assigning every high-risk action to its risk owner automatically
▪️ Prompting risk champions to complete their updates
▪️ Showing GRC champions the compliance obligations they need to act on
▪️ Managing board meeting preparation, papers and follow-ups

The challenge has always been cost. 
Paying for every small automation to be built is hard to justify. 

Microsoft answered part of this by including Power Automate in Microsoft 365, yet few people use it, because learning how to build flows takes time.

This is where Claude changes things. 

You describe the process in plain language, and Claude turns it into a Power Automate flow that you import into your own Microsoft 365. 

The flows run on your own connections, inside the tools your IT team already provides and governs. 

You can see every step, change it, and ask Claude to adjust it again.

So I built a skill for Claude that does exactly this, 

and I am sharing it openly.

✅ Open source under the Apache 2.0 licence, free to use and adapt. Please keep the credit.
✅ Written in plain English, so nothing is hidden. Read it, change it and fit it to your own environment.
✅ Claude writes a specification first and builds nothing until you confirm it.
✅ The output is ready-to-import packages, with an install checklist and a build record for your files.

The repository also has a space for sample flows. I will be adding some of my own there soon.

🔍 To get the skill, search GitHub for asayrafy/ClaudePowerAutomate. 

The repository has full instructions on how to install and use it, and a project page with a download button.

As with any automation, review and test each flow before it goes live.
