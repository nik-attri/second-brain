Job Title: Salesforce DevOps Engineer
Job Location: Dubai, United Arab Emirates
Budgeted Salary: AED 20,000 – 25,000 Monthly (Salary According to Candidate Experience)

Job Requirements:
- Minimum 3+ years of Salesforce experience, with strong hands-on experience in Salesforce DevOps or release management.
- Strong knowledge of Salesforce deployment architecture, metadata, sandboxes, and environments.
- Hands-on experience with Git and source control workflows.
- Experience with Salesforce DevOps tools such as Gearset, Copado, AutoRABIT, Flosum, or similar platforms.
- Strong experience with Salesforce CLI (SF CLI) and deployment automation.
- Experience building CI/CD pipelines using tools such as GitHub Actions, Azure DevOps, Jenkins, GitLab CI, or Bitbucket Pipelines.
- Understanding of Apex testing, code coverage, Lightning Web Components, permission sets, profiles, and Salesforce metadata dependencies.
- Strong troubleshooting and release-management skills.
- Understanding of Agile/Scrum software delivery practices.
- Experience supporting large-scale or multi-cloud Salesforce implementations.
- Experience with automated testing and static code analysis.
- Knowledge of Salesforce security, governance, and enterprise release management practices.
- Experience working with distributed development teams and multiple parallel Salesforce projects.

Preferred Certifications:
- Salesforce Certified Development Lifecycle and Deployment Architect

Key Responsibilities:
- Design, implement, and maintain CI/CD pipelines for Salesforce.
- Manage Salesforce deployments across multiple environments and sandboxes.
- Maintain source control strategies using Git and branching best practices.
- Automate build, validation, testing, and deployment processes.
- Support Salesforce metadata deployments using Salesforce CLI (SF CLI) and related tools.
- Manage environment synchronization, sandbox refreshes, and release readiness.
- Resolve deployment conflicts, metadata dependencies, and release issues.
- Implement automated quality checks, static code analysis, and test execution.
- Work with developers and QA teams to improve release quality and reduce deployment failures.
- Maintain rollback, backup, and recovery procedures for Salesforce releases.
- Monitor CI/CD pipelines and troubleshoot failed builds and deployments.
- Support release governance, change management, and production deployment processes.
- Maintain technical documentation for deployment procedures and DevOps standards.
