Teaching a robot a new task could eventually become as simple as showing it a video.

Researchers at NYU's AI4CE Lab developed VLM See, Robot Do, a system that interprets human demonstration videos and turns them into robot action plans.

The pipeline has three main stages:

• Keyframe selection to identify important moments in the demonstration
• Visual perception to extract information from those moments
• Vision Language Model reasoning to interpret the demonstration and generate the robot action plan

For keyframe selection, the system uses MediaPipe to detect hand keypoints and calculate hand speed. Valleys in the resulting speed profile are then used to select keyframes.

The researchers collected human demonstrations across three types of tasks:

• Vegetable organisation
• Garment organisation
• Wooden block stacking

In the vegetable organisation example, a person places objects into specific containers one by one.

The robot then executes the task in the same order demonstrated by the human.

What I find interesting is how this changes the way we might teach robots.

Instead of manually specifying every action, we can show a robot a human demonstration and use visual perception and VLM reasoning to convert what happened into an actionable plan.

It is a fascinating direction for combining Vision Language Models, imitation learning and robot manipulation.
