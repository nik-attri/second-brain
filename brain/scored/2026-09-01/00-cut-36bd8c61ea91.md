When I came up with the name OneClickComply, I was told we were promising too much.

Which, to be fair, was a reasonable concern.

Compliance has never been one click.

It's traditionally been consultants, spreadsheets, evidence gathering, screenshots, policies and a lot of people doing things manually.

So calling a company OneClickComply was setting ourselves a fairly high bar.

But my argument was simple.

If a customer can't log in, click a button and have the software do what they need it to do, then we haven't built what we set out to build.

I didn't want to make the existing process slightly easier.

I wanted to build something I wished I'd had when I was doing all of this manually at Octopus.

Which I'm very pleased to say we achieved.
