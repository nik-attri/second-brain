Linux isn't going away. It has now been around for decades, and I wouldn't bet against it. I do miss the days of installing Linux on physical servers, though.

Cloud hasn't made Linux less important. If anything, I think understanding Linux is more important now.

Infrastructure has changed a lot. We've gone from physical servers to virtual machines, from data centres to cloud platforms, and from doing a lot of things manually to increasingly automated environments.

But when something goes wrong, the same fundamentals still matter.
Someone still needs to understand what's happening with the operating system. Processes, memory, CPU, storage, networking, permissions, logs and services don't disappear just because the infrastructure is running in the cloud.

You might not manage every server the way we once did, but knowing what's happening underneath the platform is still incredibly useful when something isn't behaving as expected.

Technology will keep changing. I'll still want to know what's happening underneath it.
