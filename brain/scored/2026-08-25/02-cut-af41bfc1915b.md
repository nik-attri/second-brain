AI coding gets far more useful when the workflow around it becomes repeatable. I’ve been using the latest Microsoft HVE-Core with the GitHub Copilot desktop app, and the combination is changing how I think about AI-assisted development.

HVE-Core is a free, open-source agentic framework built around specialized agents, prompts, instructions, and skills that support solution development from early discovery through implementation and review.

It’s also evolving quickly. Publicly released only since January 2026, HVE-Core has already streamlined core workflows and reshaped familiar agents — including PR Reviewer becoming the broader Code Review agent.

The biggest improvement for me is RPI:
Research → Plan → Implement → Review → Follow-up

Rather than manually hopping between agents, the RPI Agent guides work through the appropriate stages: deciding when research is needed, creating a plan, implementing it, reviewing the result, and routing unresolved items back where they belong.

Along the way, it creates durable artifacts — research findings, plans, implementation evidence, review results, and decisions.
That makes the work auditable, reusable, and resumable instead of disappearing into chat history.

HVE-Core also reaches beyond implementation. Design Thinking can help define the problem space, Research can establish evidence, and specialized capabilities like Code Review can add another engineering perspective when needed.

This is where Copilot Desktop fits especially well for me.

Each session has its own context and worktree, so I can run isolated efforts without worrying about one interfering with another. I can inspect plans and changes, ask side questions, move into a pull request, and even review and approve that PR without leaving Copilot Desktop.
